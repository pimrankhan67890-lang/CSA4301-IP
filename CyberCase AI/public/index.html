SYSTEM NOTES / 03

Evidence first.
Assumptions last.

CyberCase helps organize digital incident materials. It is designed to make information easier to review, not to decide who's guilty.

01 / INPUT

Bring your evidence

Upload up to five files or describe the situation. Supported inputs include PDF, images, plain text, email text and CSV.

02 / ANALYSIS

Connect the details

Gemini helps extract visible facts and infer a draft timeline. The app calculates a SHA-256 digest for each uploaded file to help identify the exact copy analyzed.

03 / REPORT

Prepare the next step

Review missing information, generate a neutral report, export it and use the official reporting link shown with your case guidance.

DATA & SAFETY

Know the limits

Hashes help detect file changes; they do not prove that the original file was authentic. AI may make mistakes. Verify names, dates, amounts and claims against originals.

CYBERCASE / PRIVACY & SAFETY
Your evidence stays yours.
Files are handled in server memory and are not written to this application's disk. When Gemini is configured, uploaded evidence and the incident description are sent to Google's Gemini API to generate the requested analysis. Avoid uploading material you are not authorized to share. Saved cases contain analysis metadata only and stay in this browser's local storage.
